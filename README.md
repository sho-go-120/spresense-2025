## 9. セットアップ時の注意（WiFi設定）

各 `config.h` / `configapp*.h` 内の WiFi 認証情報は、公開のため `********` にマスクしています。
ビルド前に、ご自身の環境に合わせて書き換えてください。

```c
#define  AP_SSID        "あなたのWiFiのSSID"
#define  PASSPHRASE     "あなたのWiFiのパスワード"
```

**対象ファイル:**
- `HTTPSecureClient/config.h`
- `HTTPClient/config.h`
- `app/configapp.h`
- `app1/configapp1.h`

> ℹ️ `server/venv/`、`.DS_Store`、`*.code-workspace` はリポジトリに含めていません。
